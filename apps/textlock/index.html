      Make it stick at the phone level

      TextLock is a commitment device — a promise with a timer and some friction, kept honestly. It cannot reach into your phone's messaging app. If you want hard enforcement for the same hours, set it up once in your phone's own controls:

      • iPhone: Settings → Screen Time → App Limits → add Messages (and WhatsApp, etc.), or turn on a Focus that silences and hides them. Ask someone you trust to hold the Screen Time passcode.
      • Android: Settings → Digital Wellbeing → App timers → set a timer on Messages, or use Focus mode to pause it for the evening.
      • Both: start TextLock for the same window so you have a countdown, a place to park almost-sent texts, and a record of the locks you kept.
