# Design (thin): Gesso for iOS, option A, "thinnest shell": one WKWebView, one scheme handler, one {op,args} bridge

A SwiftUI app of roughly 700 lines hosts the unchanged Gesso web app from its bundle at the pinned origin gesso-app://app (WKURLSchemeHandler, explicit MIME types, no network, default persistent data store). The web app gains one seam, ui/platform.js, which reads an injected window.__gessoNative flag and talks to a single WKScriptMessageHandlerWithReply handler named `gesso` with {op, args} messages; every function in it has the web behaviour as its fallback, so elsewhere.quest is untouched in behaviour. Nine ops cover goals 1–6: photo.pick (PHPicker, bytes handed over as a scheme-served temp file, never base64), image.decode (ImageIO/CIRAW for DNG and ProRAW, rendered to an sRGB JPEG that becomes the draft's stored original so restore needs no Swift), photos.save (PHPhotoLibrary add-only with a real result), share (UIActivityViewController), subject.mask (VNGenerateForegroundInstanceMaskRequest + VNDetectContoursRequest returning polygons that enter Outline's existing polygon recipe, zero pipeline changes), haptic, xfer.release, clipboard.write and ping. Swift calls into the page only through window.gesso.flush(). Durable storage is a property of the default WKWebsiteDataStore plus the pinned origin. Diffs to existing files are small and listed line by line; new tests cover the seam in node, a native-mode Playwright run with a stubbed handler, XCTest for the scheme handler and the fitWorkingSize port, and one XCUITest for pick→save on the simulator. Build order is six steps, about five to six working days.

# Gesso for iOS — option A, "thinnest shell"

Everything that can stay in the web app stays there. The Swift surface is: a
window, a web view, a file server for the bundle, one message handler that
dispatches named ops, and the five platform calls the web genuinely cannot make
(photo picker, Photos write, share sheet, RAW decode, Vision mask) plus haptics.
Nothing in `lib/`, the renderer, the workers or the edit model changes. The web
app keeps working byte-for-byte on elsewhere.quest: the only new module,
`ui/platform.js`, is inert when the injected flag is absent.

Confidence notes are inline as **[high]**, **[medium-high]**, **[medium]** with
the fallback next to them.

## 2. Serving the web app

### Origin and scheme

The page is loaded from **`gesso-app://app/gesso/`**. Scheme `gesso-app`, host
`app`, path `/gesso/` so every relative URL in the app (`./sw.js`, `./icon.svg`,
`manifest start_url: ./`, `new URL('../workers/…', import.meta.url)`) resolves the
same way it does under `https://elsewhere.quest/gesso/`. The origin
`gesso-app://app` is the key of IndexedDB `gesso` and of every `gesso:*`
localStorage entry: **it is pinned forever**. Changing scheme, host or serving the
app from a second origin (a `file://` splash, a different host for a probe build)
silently orphans every draft. A unit test asserts the constant.

Precedent: Capacitor serves every iOS app this way (`capacitor://localhost` via
`WKURLSchemeHandler`), and its documented storage loss when the scheme changed is
the warning above in production form **[high]**.

- `file://` is not used anywhere **[high]**: opaque origin, IndexedDB and module
  workers unreliable, `new URL(import.meta.url)` fetches fail.
- Service workers are not available to a custom-scheme page (only App-Bound
  Domains over https) **[high]**, so the app skips registration natively (§6).
- Dedicated and module workers load from a custom scheme **[medium-high]**; both
  the export and heal paths have main-thread fallbacks, and a probe row proves it
  on the device (§9).
- Secure context: a custom scheme is **not** a secure context without private
  API **[medium]**. Consequences, all tolerated by the app already:
  `navigator.storage.persist` undefined (store.js:60 returns false),
  `navigator.clipboard` undefined (probe falls back to execCommand; the native
  `clipboard.write` op makes it nicer), no service worker (skipped anyway).
  IndexedDB, createImageBitmap, OffscreenCanvas, Workers and WebGL do not
  require a secure context. If the device probe says `isSecureContext: true`,
  nothing changes.

### `AppScheme.swift` — the handler

```swift
final class AppSchemeHandler: NSObject, WKURLSchemeHandler {
    static let scheme = "gesso-app", host = "app", origin = "gesso-app://app"
    static let appPrefix = "/gesso/", xferPrefix = "/xfer/"
    private let webRoot: URL          // Bundle.main.resourceURL!/web
    private let xfer: Xfer
    private var live = Set<ObjectIdentifier>()   // tasks not yet stopped (didReceive after stop throws)
    private let io = DispatchQueue(label: "gesso.scheme", qos: .userInitiated)

    func webView(_ webView: WKWebView, start task: WKURLSchemeTask) {
        live.insert(ObjectIdentifier(task))
        guard let url = task.request.url, url.host == Self.host, task.request.httpMethod == "GET",
              let file = resolve(url) else { return finish(task, status: 404) }
        io.async {
            let data = try? Data(contentsOf: file, options: .mappedIfSafe)   // mmap: a 70 MB DNG is not copied
            DispatchQueue.main.async {
                guard let data else { return self.finish(task, status: 404) }
                self.finish(task, status: 200, data: data, type: Self.mime(for: file.pathExtension))
            }
        }
    }
    func webView(_ webView: WKWebView, stop task: WKURLSchemeTask) { live.remove(ObjectIdentifier(task)) }

    /// `/gesso/` or `/gesso/?probe=1` -> index.html; `/gesso/<path>` -> web/<path>; `/xfer/<name>` -> temp file.
    /// The query is ignored. Anything with `..`, an absolute component, or outside the root is nil (404).
    private func resolve(_ url: URL) -> URL? {
        let path = url.path   // already percent-decoded, query stripped
        if path.hasPrefix(Self.appPrefix) {
            var rel = String(path.dropFirst(Self.appPrefix.count))
            if rel.isEmpty || rel.hasSuffix("/") { rel += "index.html" }
            return safeJoin(webRoot, rel)
        }
        if path.hasPrefix(Self.xferPrefix) {
            return xfer.url(forName: String(path.dropFirst(Self.xferPrefix.count)))  // only names Xfer handed out
        }
        return nil
    }
    private func safeJoin(_ root: URL, _ rel: String) -> URL? {
        let parts = rel.split(separator: "/", omittingEmptySubsequences: true)
        guard !parts.contains(".."), !parts.contains(where: { $0.hasPrefix(".") }) else { return nil }
        let u = root.appendingPathComponent(rel).standardizedFileURL
        return u.path.hasPrefix(root.standardizedFileURL.path) && FileManager.default.fileExists(atPath: u.path) ? u : nil
    }
    private func finish(_ task: WKURLSchemeTask, status: Int, data: Data = Data(), type: String = "text/plain; charset=utf-8") {
        guard live.remove(ObjectIdentifier(task)) != nil else { return }   // stopped meanwhile
        var headers = ["Content-Type": type, "Content-Length": String(data.count), "Cache-Control": "no-store"]
        if type.hasPrefix("text/html") { headers["Content-Security-Policy"] = Self.csp }
        let resp = HTTPURLResponse(url: task.request.url!, statusCode: status, httpVersion: "HTTP/1.1", headerFields: headers)!
        task.didReceive(resp); task.didReceive(data); task.didFinish()
    }
    static func mime(for ext: String) -> String {
        switch ext.lowercased() {
        case "html": return "text/html; charset=utf-8"
        case "js", "mjs": return "text/javascript; charset=utf-8"      // module scripts are MIME-strict
        case "css": return "text/css; charset=utf-8"
        case "svg": return "image/svg+xml"
        case "webmanifest", "json": return "application/manifest+json"  // json only for the manifest here
        case "png": return "image/png"
        case "jpg", "jpeg": return "image/jpeg"
        case "heic", "heif": return "image/heic"
        case "dng": return "image/x-adobe-dng"
        case "txt": return "text/plain; charset=utf-8"
        default: return "application/octet-stream"
        }
    }
    // No network, ever. blob: and data: stay open: the long-press <img> object URL, the
    // shimmer's SVG data-URL mask (remove.js), and the probe's blob: worker all need them.
    static let csp = "default-src gesso-app: blob: data: 'unsafe-inline'; connect-src gesso-app: blob: data:; " +
                     "img-src gesso-app: blob: data:; worker-src gesso-app: blob:; style-src gesso-app: 'unsafe-inline'"
}
```

Facts the handler is built on: `didReceive` after `stop` raises an ObjC exception
(hence `live`) **[high]**; WebKit does not hand the request body to a scheme
handler, so there is no POST path and uploads go through the message bridge
**[medium-high]**; MIME for `.js` must be a JavaScript type or every module is
blocked with a blank page **[high]**. Range requests are ignored (whole-file 200
is correct for `fetch()` and `createImageBitmap`; Range only matters for media
elements, which Gesso has none of). `Cache-Control: no-store` keeps WebKit from
caching a bundle file across app updates; a per-build `web/version.txt` (served,
shown by the probe) is the versioning.

Caching/versioning summary: the bundle *is* the shell; there is no cache layer to
bust; the web app and the Swift app ship as one unit, and
`__gessoNative.ops` (below) lets a newer web bundle feature-detect an older
shell if they ever drift (they can't within one build, but the habit is cheap).

## 3. The bridge contract

One handler, one message shape, one reply shape. JS → Swift:

```js
window.webkit.messageHandlers.gesso.postMessage({ op: 'photos.save', args: { base64, name, type } })  // -> Promise
```

Swift replies through `replyHandler(result, nil)` with a dictionary that always
has `ok`:

- success: `{ ok: true, ...fields }`
- failure: `{ ok: false, code, message }` with `code` in
  `cancelled | denied | unsupported | failed | timeout | badArgs | unknownOp`

`platform.call()` turns `ok:false` into a rejected promise whose `.code` is the
code, so callers write `catch (e) { if (e.code === 'cancelled') return; … }`.
`replyHandler(nil, "…")` (WebKit's own error path) is used only for a malformed
message. Every op path replies exactly once, including on dismissal, cancellation
and thrown errors (a `Replied` guard in each op) — an op that never replies hangs
a promise forever, so this is the one hard rule on the Swift side.

Swift → JS: only `window.gesso.flush()` (and, if the keyboard fallback is ever
needed, `window.gesso.keyboard(px)`), always via `evaluateJavaScript` with the
`window.gesso &&` guard, because `window.gesso` is set at the end of `main()`.

Injected flag (`.atDocumentStart`, main frame, page world, so it exists before
`app.js` evaluates):

```js
window.__gessoNative = Object.freeze({
```

### The ops

| op | args | reply (`ok:true` plus) | errors | transfer | JS timeout |
|---|---|---|---|---|---|
| `ping` | `{}` | `{ v, build, ios, model, memoryGB, webVersion }` | — | JSON | 2 s |
| `photo.pick` | `{}` | `{ url, name, type, bytes }` — `url` is `gesso-app://app/xfer/<uuid>.<ext>`, `type` a MIME from the UTType, `name` the provider's suggested name | `cancelled`, `failed` | file via scheme, any size | none (user is in the picker) |
| `image.decode` | `{ url, maxPixels, maxSide?, quality? }` | `{ url (JPEG), natW, natH, w, h, downscaled }` — `natW/natH` oriented | `unsupported` (ImageIO can't open it), `failed`, `badArgs` | file in, file out via scheme | 30 s |
| `photos.save` | `{ base64, name, type }` | `{ }` | `denied` (add-only permission refused/restricted), `failed` (PHPhotoLibrary error message) | base64 in (3–12 MB JPEG → 4–16 MB string, one copy) | 30 s |
| `share` | `{ base64, name, type }` | `{ completed: bool, activity: string|null }` | `failed` | base64 in → temp file → UIActivityViewController | none |
| `subject.mask` | `{ base64 (JPEG of the analysis frame), w, h, x, y (0..1 in that frame), all?: bool }` | `{ polys: [[x,y,...], ...] in that frame's px, outer rings, largest first, w, h, instances }` | `unsupported` (< iOS 17 / no result), `failed`, `timeout` | ~0.3–1 MB base64 in, JSON out | 15 s |
| `haptic` | `{ kind: 'tick'|'light'|'medium'|'success'|'warning'|'error' }` | `{}` | — | JSON | not awaited |
| `xfer.release` | `{ url }` | `{}` | — | — | not awaited |
| `clipboard.write` | `{ text }` | `{}` | — | ≤ 64 KB | 2 s |

Why base64 for the JPEG and not a file: WebKit gives the scheme handler no
request body, and a 16 MB string across `postMessage` costs ~100 ms and one copy;
chunking is not needed below ~50 MB. Why files for photos: a ProRAW DNG is
25–75 MB and would be a 100 MB string plus a 100 MB decode on the JS side.

### `Bridge.swift`

```swift
struct BridgeError: Error { let code: String; let message: String }
typealias Reply = (Result<[String: Any], BridgeError>) -> Void
protocol OpProvider { var ops: [String: ([String: Any], @escaping Reply) -> Void] { get } }

final class Bridge: NSObject, WKScriptMessageHandlerWithReply {
    private var table: [String: ([String: Any], @escaping Reply) -> Void] = ["ping": { _, r in r(.success(Bridge.identity())) }]
    var opNames: [String] { table.keys.sorted() }
    func install(_ providers: OpProvider...) { for p in providers { table.merge(p.ops) { _, new in new } } }
    func userContentController(_ ucc: WKUserContentController, didReceive m: WKScriptMessage,
                               replyHandler: @escaping (Any?, String?) -> Void) {
        guard let body = m.body as? [String: Any], let op = body["op"] as? String else { return replyHandler(nil, "bad message") }
        guard let fn = table[op] else { return replyHandler(["ok": false, "code": "unknownOp", "message": op], nil) }
        var done = false
        fn(body["args"] as? [String: Any] ?? [:]) { result in
            guard !done else { return }; done = true           // exactly one reply per call
            switch result {
            case .success(var d): d["ok"] = true; replyHandler(d, nil)
            case .failure(let e): replyHandler(["ok": false, "code": e.code, "message": e.message], nil)
            }
        }
    }
    static func flagScript(ops: [String]) -> String { /* the snippet above, ops JSON-encoded */ }
}
```

New ops are a dictionary entry in a provider; nothing else in Swift changes.

### `PhotosOps.swift`

```swift
final class PhotosOps: NSObject, OpProvider, PHPickerViewControllerDelegate {
    var ops: [String: ([String: Any], @escaping Reply) -> Void] {
        ["photo.pick": pick, "photos.save": save, "share": share]
    }
    private var pending: Reply?
    func pick(_ args: [String: Any], _ reply: @escaping Reply) {
        var c = PHPickerConfiguration(photoLibrary: .shared())   // no NSPhotoLibraryUsageDescription needed
        c.filter = .images; c.selectionLimit = 1
        c.preferredAssetRepresentationMode = .current            // HEIC stays HEIC, ProRAW stays DNG, no transcode
        let vc = PHPickerViewController(configuration: c); vc.delegate = self
        pending = reply; host.present(vc, animated: true)
    }
    func picker(_ picker: PHPickerViewController, didFinishPicking results: [PHPickerResult]) {
        picker.dismiss(animated: true)
        guard let reply = pending else { return }; pending = nil
```

```swift
final class DecodeOps: OpProvider {
    var ops: [String: ([String: Any], @escaping Reply) -> Void] { ["image.decode": decode] }
    func decode(_ args: [String: Any], _ reply: @escaping Reply) {
        guard let s = args["url"] as? String, let src = xfer.file(for: s) else { return reply(.failure(.init(code: "badArgs", message: "url"))) }
        let maxPixels = args["maxPixels"] as? Int ?? 24_500_000, maxSide = args["maxSide"] as? Int ?? 8192
        let quality = args["quality"] as? Double ?? 0.98
        DispatchQueue.global(qos: .userInitiated).async {
            do {
                guard let source = CGImageSourceCreateWithURL(src as CFURL, nil),
                      let props = CGImageSourceCopyPropertiesAtIndex(source, 0, nil) as? [CFString: Any],
                      let pw = props[kCGImagePropertyPixelWidth] as? Int, let ph = props[kCGImagePropertyPixelHeight] as? Int
                else { throw BridgeError(code: "unsupported", message: "ImageIO can't open it") }
                let orient = props[kCGImagePropertyOrientation] as? UInt32 ?? 1
                let (natW, natH) = (5...8).contains(orient) ? (ph, pw) : (pw, ph)       // same rule as orientedDims()
                let fit = fitWorkingSize(natW, natH, maxPixels: maxPixels, maxSide: maxSide)  // exact port, §7
                let opts: [CFString: Any] = [kCGImageSourceCreateThumbnailFromImageAlways: true,
                                             kCGImageSourceCreateThumbnailWithTransform: true,    // applies EXIF, like createImageBitmap
                                             kCGImageSourceThumbnailMaxPixelSize: max(fit.w, fit.h),
                                             kCGImageSourceShouldCacheImmediately: true]
                guard let cg = CGImageSourceCreateThumbnailAtIndex(source, 0, opts as CFDictionary) else { throw BridgeError(code: "failed", message: "decode") }
                // Draw into a context of exactly fit.w x fit.h in sRGB: ImageIO's rounding may differ by a pixel,
                // and the draw is also the colour-managed conversion (ProRAW is linear/wide gamut).
                let cs = CGColorSpace(name: CGColorSpace.sRGB)!
                let ctx = CGContext(data: nil, width: fit.w, height: fit.h, bitsPerComponent: 8, bytesPerRow: 0, space: cs,
                                    bitmapInfo: CGImageAlphaInfo.noneSkipLast.rawValue)!
                ctx.interpolationQuality = .high
                ctx.draw(cg, in: CGRect(x: 0, y: 0, width: fit.w, height: fit.h))
                let out = ctx.makeImage()!
                let dest = try xfer.create(ext: "jpg")
                let d = CGImageDestinationCreateWithURL(dest.fileURL as CFURL, UTType.jpeg.identifier as CFString, 1, nil)!
                CGImageDestinationAddImage(d, out, [kCGImageDestinationLossyCompressionQuality: quality] as CFDictionary)
                guard CGImageDestinationFinalize(d) else { throw BridgeError(code: "failed", message: "encode") }
                reply(.success(["url": dest.url, "natW": natW, "natH": natH, "w": fit.w, "h": fit.h, "downscaled": fit.downscaled]))
            } catch let e as BridgeError { reply(.failure(e)) } catch { reply(.failure(.init(code: "failed", message: "\(error)"))) }
        }
    }
}
```

reasonable default rendering **[medium-high]**. If ProRAW looks flat through
`CGImageSource` (it is a Linear DNG), the swap is `CIRAWFilter(imageURL:)` with
`.scaleFactor = fit.w / natW` and `CIContext.createCGImage(_:from:format:colorSpace:)`

question). The stored original for a RAW import is this JPEG (§4, T02), which is

```swift
final class SubjectOps: OpProvider {
    var ops: [String: ([String: Any], @escaping Reply) -> Void] { ["subject.mask": mask] }
    func mask(_ args: [String: Any], _ reply: @escaping Reply) {
        guard #available(iOS 17, *) else { return reply(.failure(.init(code: "unsupported", message: "iOS 17"))) }
        guard let b64 = args["base64"] as? String, let data = Data(base64Encoded: b64),
              let x = args["x"] as? Double, let y = args["y"] as? Double else { return reply(.failure(.init(code: "badArgs", message: ""))) }

            do {
                guard let src = CGImageSourceCreateWithData(data as CFData, nil), let cg = CGImageSourceCreateImageAtIndex(src, 0, nil)
                else { throw BridgeError(code: "badArgs", message: "image") }
                let (w, h) = (cg.width, cg.height)
                let handler = VNImageRequestHandler(cgImage: cg, orientation: .up)
                let req = VNGenerateForegroundInstanceMaskRequest()
                try handler.perform([req])
                guard let obs = req.results?.first else { return reply(.success(["polys": [], "w": w, "h": h, "instances": 0])) }
                // The instance under the finger: obs.instanceMask is a low-res OneComponent8 label map, 0 = background.
                let label = Self.label(in: obs.instanceMask, atNormalised: x, y)
                let chosen: IndexSet = (label > 0 && !all) ? IndexSet(integer: label) : obs.allInstances
                let soft = try obs.generateScaledMaskForImage(forInstances: chosen, from: handler)   // Float32, image size
                let binary = Self.threshold(soft, at: 0.5)                                              // 8-bit grey CGImage, 0/255
                let contours = VNDetectContoursRequest()
                contours.contrastAdjustment = 1; contours.detectsDarkOnLight = false; contours.maximumImageDimension = 1024
                try VNImageRequestHandler(cgImage: binary, orientation: .up).perform([contours])
                let rings = (contours.results?.first?.topLevelContours ?? []).map { c -> [Double] in
                    c.normalizedPoints.flatMap { [Double($0.x) * Double(w), (1 - Double($0.y)) * Double(h)] }   // Vision is bottom-left origin
                }.sorted { Self.area($0) > Self.area($1) }
                reply(.success(["polys": rings, "w": w, "h": h, "instances": obs.allInstances.count, "hit": label > 0]))
            } catch let e as BridgeError { reply(.failure(e)) } catch { reply(.failure(.init(code: "failed", message: "\(error)"))) }
        }
    }
}
```

## 4. How each goal is met

**Goal 1 — Photos in and out.** In: `#choose`, the dock tap on the start screen,
`askNewPhoto` and Discard all go through one `choosePhoto()` in app.js, which
calls `platform.pickPhoto()` natively and `fileInput.click()` otherwise. The pick
arrives as a `File` built from a `fetch()` of the scheme-served temp file and
goes into the existing `importFile(file)` — `earlyFile` and picked-beats-restore
semantics are preserved because `choosePhoto` parks a pick that lands before
`importFile` exists. Out: the Save sheet's primary button calls `photos.save`
and treats only `ok:true` as saved (`markSaved`, "Saved to Photos.", no coach
line); `denied`/`failed` route to `share` (UIActivityViewController: Files,
AirDrop, Messages); a secondary "Share…" button is shown natively. The
long-press fallback is never shown natively.

**Goal 2 — Vision subject lift.** In Outline mode a tap (today a no-op: a
tap-sized loop is dropped by `TINY_PT2`) becomes "lift the subject under the
finger" when `subject.mask` is available. JS sends the same analysis frame the
lasso works on (`ed.readOutput({ maxSide: 1024 })`, re-encoded to a small JPEG),
gets polygons back in that frame's px, runs them through the identical
`toSource` matrix, `simplifyPolygon`, `polygonRecord`, `outlineBox`,
`exceedsAreaCap` and builds the identical `{kind:'outline', poly}` job (Remove)
or entry (Light). Everything downstream — rubTile, land, Try another,
recipeRecord, shimmer, overlay, replayPaint/outlinePaint/paintMask, the Amount
ruler, autosave, undo — is untouched (the "option A, vector" path from the
touchpoint map). Raster masks (option B) are not needed for v1.

**Goal 3 — Durable storage.** `WKWebViewConfiguration.websiteDataStore = .default()`
is persistent, lives in the app container and is deleted only with the app;
Safari's 7-day script-storage cap applies to Safari browsing, not to an app's
own web view **[medium-high]**. The pinned origin keeps the database reachable
across updates. `store.js`, `autosave.js` and `draft.js` do not change. The
content process can still be killed under pressure: `flush()` on
`scenePhase != .active` and on memory warnings, plus `webViewWebContentProcessDidTerminate → reload()`,
bound the loss to the 300 ms debounce, and the reload lands on the restore path.
Migration from Safari drafts: not required (different origin, by design).

**Goal 4 — Haptics.** `platform.haptic(kind)` is a non-awaited `call('haptic')`
with a 50 ms throttle for `tick`. Moments: ruler detent (`ruler-view.js flash()`)
→ tick; Done/commit (`editor.js closeTool({cancel:false})`, `commit`) → light;
caption snap-guide engage (`text.js`) → light; Outline lift → light; a fill
landing (`remove.js land`) → success; Save to Photos ok → success; "Couldn't
remove that" and the area-cap tip → warning. Undo/redo: none (noisy). Web: no-op.

**Goal 5 — Native decode.** `pickPhoto()` routes by the MIME Swift reports: a
type WebKit decodes (jpeg, png, heic/heif, webp, gif, avif, bmp) is fetched as
is; anything else (DNG, TIFF, camera RAW, unknown) goes through `image.decode`
first and only the rendered JPEG is fetched. Inside `decodeForEditing`, a
`createImageBitmap` rejection on a file that came from the picker retries via
`image.decode` (the file's xfer URL is remembered in a WeakMap). The rendered
JPEG becomes the Blob stored by `autosave.startDraft`, so restore and GL-loss
recovery decode it with `createImageBitmap` like any other photo, at exactly
its own size: no decoder marker, no `reviveInfo` change, no Swift on the
restore path. The one invariant the Swift side must honour is `w*h ≤ maxPixels`
and `max(w,h) ≤ maxSide` (else restore's `fitWorkingSize` would shrink the JPEG
by a pixel and reject the draft); the exact port of `fitWorkingSize` guarantees
it and is unit-tested against a table generated by node (§9).

**Goal 6 — App Store readiness.** No network code exists; the navigation policy
cancels every non-`gesso-app://app` navigation; the CSP on `index.html` forbids
every other scheme; no ATS exceptions; `PrivacyInfo.xcprivacy` declares no
collection, no tracking and no required-reason APIs (§8). Install line, probe
install rows and SW registration are off natively. Icon from `icon.svg`
("Pigment Wheel"), launch screen = the Ground colour (no white flash, no
storyboard). iPhone only; iPad is a device-family flip plus the popover anchor
already in `share`.

```js
// touches a browser global at import time (node tests import this file).

const flag = () => globalThis.__gessoNative ?? null;
const handler = () => globalThis.webkit?.messageHandlers?.gesso ?? null;

export const isNative = !!(flag() && handler());
export const native = isNative ? flag() : null;
const ops = new Set(native?.ops ?? []);
export const has = (op) => isNative && ops.has(op);

export class NativeError extends Error { constructor(code, message) { super(message || code); this.code = code; } }

export function call(op, args = {}, { timeoutMs = 0 } = {}) {
  if (!has(op)) return Promise.reject(new NativeError('unsupported', op));
  let p;
  try { p = Promise.resolve(handler().postMessage({ op, args })); } catch (err) { p = Promise.reject(err); }
  p = p.then((r) => {
    if (!r || typeof r !== 'object') throw new NativeError('failed', `${op}: bad reply`);
    if (r.ok !== true) throw new NativeError(r.code ?? 'failed', r.message);
    return r;
  });
  if (!timeoutMs) return p;
  let t = 0;
  return Promise.race([p, new Promise((_, rej) => { t = setTimeout(() => rej(new NativeError('timeout', op)), timeoutMs); })])
    .finally(() => clearTimeout(t));
}
```

```js
async function liftSubject(ed, t) {
  const st = ed.committed;
  const img = ed.readOutput({ maxSide: ANALYSIS_PX, tone: true });   // what the user sees; same px grid as the lasso's analysis
  const [px, py] = t.start;
  ed.panel.showTip('Finding the subject…');
  let r;
  try { r = await subjectMask(img, px, py); } catch (err) { ed.panel.showTip("Couldn't find a subject there."); return; }
  if (ed.committed !== st || !r.polys.length || !r.hit) { if (ed.committed === st) ed.panel.showTip('Tap on the subject.'); return; }
  const { kx, ky } = t;
  const toSource = multiply(outputToSource(st.crop, st.source.w, st.source.h), [1 / kx, 0, 0, 1 / ky, 0, 0]);
  const polyS = Float32Array.from(polygonRecord(transformPolygon(simplifyPolygon(r.polys[0], 0.75), toSource)));
  const { width: W, height: H } = ed.renderer.size;
  const box = outlineBox(polyS, W, H);
  if (!box) return;
  if (exceedsAreaCap(box, W, H)) { ed.panel.showTip(CAP_TIP); haptic('warning'); return; }
  haptic('light');
  const job = { kind: 'outline', poly: polyS, seed: 1, attempt: 0 };
  enqueue(ed, job, (gen) => fillOutline(ed, job, gen));
  ed.refresh();
}
```

## 7. Persistence and migration

- IndexedDB `gesso` and `gesso:*` localStorage live under `gesso-app://app` in the
  default data store; no schema or code changes; drafts survive app updates
  (bundle changes do not touch the data store) and are deleted with the app.
- No migration from Safari or the Home Screen PWA (different origins, accepted).
- Future-proofing: if a second origin is ever needed (e.g. an iPad-specific
  entry), serve it from the same origin with a different path, never a different
  scheme or host.
- The `fitWorkingSize` port must stay byte-identical to `lib/image-io.js:23-42`
  (same IEEE-754 operations in the same order: `min(1, sqrt(area/(w*h)), side/w, side/h)`,
  `floor`, the over-budget trim). The JSON table test (§9) is the contract.

## 10. Risks and mitigations

| Risk | Mitigation |
|---|---|
| Custom scheme is not a secure context and something needs one | Nothing in Gesso does; probe row confirms; clipboard has an op; persist() is tolerated. Last resort: a loopback `http://127.0.0.1` server in-app (not secure either) or private `_registerURLSchemeAsSecure` (not App Store safe) — neither planned. |
| Module workers fail to load from the scheme | Both worker users fall back to the main thread; probe row catches it; fix would be a response header, not architecture. |
| `visualViewport` does not shrink for the keyboard in WKWebView | Probe row; bridge fallback `keyboardWillChangeFrame → window.gesso.keyboard(px)` into `caption-edit.js` numbers. |
| Double safe-area insets or none | `.ignoresSafeArea()` + `.never`; probe prints env() values; CSS variable fallback fed from the flag. |
| WebContent process killed under pressure (48 MP) | Same WebKit budget as Safari **[medium]**; flush on inactive + memory warning; terminate → reload → restore; `memoryGB` seeding to 12 MP on 4 GB devices. |
| Origin drift orphans drafts | Constants with a unit test; never a second origin. |
| An op never replies → promise hangs | Single-reply guard, JS timeouts on the finite ops, cancel paths reply `cancelled`. |
| PHPicker hands over a 75 MB DNG | File via scheme, mmap read, decode in the app process, only the JPEG reaches JS. |
| ProRAW renders flat through ImageIO | Swap to `CIRAWFilter` behind the same op (15 lines). |
| Vision refuses in the simulator | Device-only feature; e2e stubs it. |
| Lockdown Mode cannot be disabled for the web view | Reworded message; documented in review notes. |
| A forgotten bundle file | `bundle-web.sh` checks SHELL at build time; the handler 404s instead of serving index.html. |
| `label.click()`/no-JS picker before app.js runs | Capture-phase preventDefault in the injected user script. |
| Remove's 20 % area cap rejects subject fills | Product decision (open question): raise the cap natively, tile it, or keep Light as the headline use of subject lift. |
